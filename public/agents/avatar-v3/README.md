# PerkOS Agent Avatars V3

Curated 3D companion archetypes used by the deterministic agent identity system.

- Files are immutable once released. New archetypes are appended, never reordered.
- Agent identity stores an archetype id, palette id, expression id, and generator version.
- Runtime state is rendered by the UI and does not change the persisted identity.
- Source renders keep transparency and generous padding for motion and status effects.
